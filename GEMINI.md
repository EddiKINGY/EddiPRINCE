# Gemini Agent Instructions (GEMINI.md)

This file persists mandatory rules and guidelines for AI coding assistants working in the **EddiPRINCE.com** repository.

---

## 1. Strict Content & Copywriting Policy (Approval First)

- **Zero Unsolicited Copy Changes**: Do NOT change, rewrite, modify, or add text or copy on the website on your own initiative.
- **Mandatory Pre-Approval Step**:
  1. Clearly outline what text changes are proposed and why.
  2. Show the exact Before and After text.
  3. Await explicit approval from the user before applying the edits to any file.

---

## 2. Image Management Policy

- **No Images Until Instructed**: All images have been removed per user instruction. Do not add, generate, or restore images until the user explicitly requests and provides guidance on how they should be added.

---

## 3. Brand & Architecture Guidelines

- **Brand Name**: `EddiPRINCE` (exact casing).
- **Architecture**: Client-side React SPA with Tailwind CSS v4. No unsolicited backends.
- **Port**: Bind only to port 3000 at 0.0.0.0.
